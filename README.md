novelty:

- Using AI agents to rapidly explore and document large, unfamiliar codebases — e.g. reverse-engineering a legacy
  iOS app's complete API surface, authentication flow, and AES/RSA encryption scheme to re-implement equivalent
  functionality on the web.

  agents for research, code generation, and verification.
- Orchestrating multi-step AI-assisted workflows — breaking ambiguous tasks into scoped, verifiable steps rather than
  trusting raw output blindly.
- Using AI tools to accelerate TypeScript migrations, React Native version upgrades, and code quality improvements
  across existing codebases.

I see AI coding tools as a force multiplier for judgment and verification skills, not a replacement for them — I
still own correctness, security, and architecture decisions on everything I ship.
